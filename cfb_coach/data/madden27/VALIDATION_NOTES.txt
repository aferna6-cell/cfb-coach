VERDICTS ON THE ORIGINAL BRIEF'S PRIORS
  CONFIRMED
  - Gun Doubles Clamp Stack = THE meta formation (new in 27; 18+ books incl. Bucs,
    Cardinals, Shotgun Classic).
  - Buccaneers book formations: Gun Doubles Clamp Stack, Gun Trips X Nasty,
    Gun 5WR Tight, Pistol Trips (Huddle.gg Bucs formation list).
  - Mtn Stick Wheel, Switch HB Wheel (Trips X Nasty); Mtn Double Post, Mtn Fork Salem,
    Mtn Post Swirl (5WR Tight); HB Dive (Pistol Trips).
  - D #1 = 49ers / Titans Saleh 4-3 (Prodigy, TimeSaver, Operation Sports); Dime 3-2 Odd.
    Texans, Multiple D, Vikings, Bengals, Raiders, Jaguars (Cover 4) all cited.
  - Cover 4 Quarters core (+ Tampa 2: both in 23 of 24 Saleh formations).
  - Stock 3-4 launch bug: DEs line up at OLB and drop into coverage (TimeSaver).
  - Run game: zone-blocking targeting improved (Sep 3 TU) → Inside Zone / Stretch;
    Aggressive blocking coach adjustment now draws holding.
  - Stunts/sims over contain: Sep 3 TU — OTs pick up contain + wide LBs.
  CORRECTED
  - "Motion Shuffle Vert Smash" → real name "Mtn Shuffle Verts Smash".
  - "Pistol Trips RZ" → no such formation; it is "Pistol Trips" (RZ is usage).
  - "HB Zone" → "HB Zone WK" in Pistol Trips.
  - "Nickel Mug" → no such formation. Saleh book: Nickel Over (home per guides),
    Nickel Single Mug, Nickel Double Mug, Nickel Load Mug, 2-4 Load Dbl Mug.
  - "DB Fire 2" → not found in any Saleh nickel/mug list. Verified sim pressures:
    Nickel Sim 2, Field Sim 3 (Double Mug / Over), Dt Mike Loop 3 (Single Mug).
  - Removed invented concept plays not present in those formations: Ohio Return /
    Flood Sail (Trips X Nasty), Quick Slants (5WR Tight), Mesh / Stick Wheel /
    HB Stretch (Clamp Stack), Cover 2 Sink, Cover 4 Drop, "Cover 1 Robber"
    (real: Cover 1 Robber Press / Cover 1 Hole).
  ADDED (missing from brief)
  - Texas Y-Stutter Wheel (Clamp Stack) — Civil.GG #1 play; beats man/zone/blitz.
  - Mesh Post, Clear Deep (5WR Tight) — Civil.GG #2 / #5.
  - Return Bench, Same Side Zone, Mtn Shuffle Mesh Rail, Y Ohio Return (Clamp Stack);
    Hi Lo Cross, Mtn Triple Slants, Mid Zone (Trips X Nasty); Flood, Stick,
    HB Stretch (Pistol Trips).
  - Sep 16 TU: longer downfield pass lead; jostle favors WRs vs lower-rated DBs;
    wrong-way man-press shading penalized (MESH-RAT no longer presses); Half Slide
    no longer flips to Full Slide (O-PROT uses Half Slide); QB Contain call no longer
    resets hot routes.
  CONTESTED
  - "Buccaneers = #1 offense": only Madden Prodigy (2026-08-11). TimeSaver
    (updated 09-11) leads with Shotgun Classic; Civil.GG with Texans — Bucs absent
    from both top 5. Kept Bucs formations because the pack is built around Clamp
    Stack, which every source rates.
  UNCONFIRMED
  - "Dollar" package: cited by TimeSaver / Operation Sports for the Saleh book, but
    not in Huddle.gg's 49ers formation list. Not used in live calls; very-long
    downs use Dime 3-2 Odd Cover 4 Quarters instead.
  - Dime 3-2 Odd play list: not yet in the databases; only Cover 4 Quarters /
    Tampa 2 (present in 23/24 formations) are called from it.
  - Delta formations (Pistol Deuce Close HB Dive, Texans Gun Tight Tight Crosses,
    Gun Off Trips Close Y Option Wheel) are Civil.GG top-10 plays from OTHER books —
    add via custom playbook.

PLAYBOOK OF RECORD, NOT A TEAM
- Each prep locks one book per side: STOCK (Buccaneers / Shotgun Classic on O,
  49ers Saleh on D — exact in-game names) or CUSTOM (full formation checklist on
  first build / switch; later preps ADD / REMOVE whole formations only).
- Stock books list only the formations whose play lists were verified; the rest of
  the in-game book exists but is not called live until modeled.
- Primary / lab teams are TBD and configurable:
    config --game madden27 --primary-team "<NFL team>"
  A set team only biases the stock-book pick; personas and call language do not change.

MACROS = MADDEN 27 CUSTOM ADJUSTMENTS (confirmed)
- EA: Create & Share → Custom Adjustments; up to 20 per side saved, 10 active per
  game; in-game LB at the line (also at the top of the play-call menu). Same system
  as CFB 27 — Aidan's hard cap of 8 O+D still applies (EA allows 10).
- EA documents the CATEGORIES (fronts, leverage, coverage behavior, protection,
  pressure looks, route concepts, hot routes, individual assignments) but not the
  exact option labels. Every option label here is tagged `approx` — match it to the
  in-game name when building. No button sequences are invented.
- All 10 catalog macros start `meta_grounded`. Postgame promotes to `proven`
  (3+ uses, >= 60% success) or demotes to `failed` (3+ uses, <= 30% success).
- 6 D + 2 O = 8 Active for USER games. CPU games = offense-only.
